\section{Projects}

\headerview{Full-Stack Todo Application}{July 2026}\\[0.1em]
{\footnotesize Next.js, TypeScript, Tailwind CSS, Prisma, MongoDB, Clerk
\ \textbullet\ \href{https://github.com/Mij-Do/Full-Stack-To-Do-app-V6}{GitHub}}\\[0.15em]
\begin{itemize}
  \item Server Components and Server Actions handle todo reads and mutations.
  \item Clerk authentication with middleware-based route protection; only the

        schemas and the todo table.

\headerview{Real Estate Listings Platform}{July 2026 --- Freelance Client Project}\\[0.1em]
{\footnotesize Next.js, TypeScript, MongoDB, Prisma, Tailwind CSS, Cloudinary
\ \textbullet\ \href{https://github.com/Mij-Do/real-state-full-stack-project}{GitHub}
\ \textbullet\ \href{https://real-state-full-stack-project.vercel.app/}{Live Demo}}\\[0.15em]
\begin{itemize}
  \item Broker-free listings: owners publish homes for sale or rent and
        buyers contact them directly by phone or WhatsApp from every listing.
  \item Admin moderation --- new listings stay pending and hidden until
        approved; a dashboard tracks live inventory and archives sold
        properties.
  \item Search and filtering by property type, price range and region.
  \item Image uploads through Cloudinary; serverless Next.js deployment on
        Vercel backed by MongoDB via Prisma.

\headerview{MijdoOS --- Interactive Developer Portfolio}{2026}\\[0.1em]
{\footnotesize React, TypeScript, Vite, Vitest, Playwright
\ \textbullet\ \href{https://github.com/Mij-Do/mijdoOs}{GitHub}
\ \textbullet\ \href{https://mijdo-os.vercel.app/}{Live Demo}}\\[0.15em]
\begin{itemize}
  \item Browser-based retro operating system: a window manager on a single
        \texttt{useReducer} --- open, close, minimize, maximize, drag and
        z-order focus --- with no router or state library.
  \item Terminal emulator with a hand-written parser, 13 commands and
        scrollback history, answering from the same typed data the windows
        render.
  \item Desktop icons drawn as merged SVG rectangles from $16{\times}16$
        pixel maps --- no image assets.
  \item ARIA roles and live regions, full keyboard operation and
        reduced-motion support; responsive across desktop, tablet and phone.
  \item 142 Vitest unit tests plus 348 Playwright runs across Chromium and
        Firefox; static build of about 87\,kB gzipped.
\end{itemize}
